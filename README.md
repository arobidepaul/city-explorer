# City Explorer

A browser game that gamifies learning your city's streets. The map shows the real street layout of downtown Chicago (the Loop, South Loop, and Near West Side), in grayscale until you explore it. Click a street segment to reveal it in color along with its name and cross streets; your progress is saved in the browser so it's still there next time you open the page.

## Run it

```
node server.js
```

Then open http://localhost:8000 in a browser. No install step, no API keys.

## Run the tests

```
node --test
```
