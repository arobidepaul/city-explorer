# City Explorer

A browser game that gamifies learning your city's streets. The city is a grid of blocks, shown in grayscale until you explore them. Click a block to reveal it in color along with its cross streets; your progress is saved in the browser so it's still there next time you open the page.

## Run it

```
node server.js
```

Then open http://localhost:8000 in a browser. No install step, no API keys.

## Run the tests

```
node --test
```
