# 0002 - Curate landmarks by hand instead of using every official entry

In the context of choosing which real landmarks to show for player orientation (R8),
facing a City of Chicago "Individual Landmarks" dataset that contains far more
officially-designated landmarks in our mapped area than a typical visitor would recognize
on sight,
we decided for hand-curating a short list of widely-recognizable buildings (e.g. the Rookery
Building, Union Station, the Chicago Theatre) and neglected plotting every officially-designated
landmark the dataset lists,
to achieve a map that helps a player orient themselves without visual clutter from obscure or
unfamiliar landmarks,
accepting that some real, officially-designated landmarks within the mapped area are left off
the map entirely.
